## log_book — Purpose of This Package

This package is the running record of **reviews of, and interactions with, the Distiller Capella model** (`tkSDISW/Distiller`, branch `master`).

### What belongs here
- **Model reviews**: what was examined (layer, elements, UUIDs), what was found, and any follow-up needed.
- **Interactions with the model**: patches applied, elements browsed or rendered, and why. Include the commit if the model was changed.
- **Observations, decisions and lessons learned** that come out of that work. Use the matching entry type for each.

### Suggested shape for an entry
- **Scope**: the layer (OA/SA/LA/PA) and the elements involved, with UUIDs where known.
- **What was done or found**
- **Outcome / next steps**
- **References**: model commit, diagrams or views, related entries.

### Conventions
- One entry per review or interaction, so each can be found and revised on its own.
- Pass `author` so each entry says who wrote it.
- Keep this package for model work. If a different subject emerges, check the existing packages before creating another.
